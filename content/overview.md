## About the exam

The HL7 FHIR Foundational Implementer exam checks a basic understanding of the FHIR specification: working with resources, RESTful operations, conformance and terminology, and security basics. It is HL7's entry-level FHIR credential and is based on **FHIR R4**.

| | |
|---|---|
| Questions | 100, multiple choice |
| Time | 3 hours |
| Passing grade | 60% |
| Guessing | No penalty, so answer every question |
| Format | Closed book, online, camera and photo ID required |

## Recommended background

- **About 6 months of hands-on FHIR experience.** There is no formal requirement, but HL7 says passing without it is very unlikely.
- **Basic XML and JSON.** You will read and fix resource instances in both formats.
- **Basic RESTful APIs.** REST is the most common way FHIR is exchanged.

## How to use this site

1. **Start with Core resource concepts** at the top of the sidebar. It teaches you to read a resource definition: elements, icons, flags, types, bindings, value sets and code systems. Every exam area builds on it.
2. Then work through the exam competencies in the sidebar. Each one lists the exam objectives from the official study guide, followed by study notes.
3. Spend the most time on the heaviest topics: **Resource Model and Structure** (25–33%) and **FHIR API Behavior** (19–33%).
4. Keep the spec open while you study: [hl7.org/fhir/R4](https://hl7.org/fhir/R4/). The exam is closed book, so practise finding answers there now and remembering them later.
5. Tick **Mark as studied** at the bottom of a topic when you are confident with it.

## Formal training offered by HL7

- HL7 FHIR Fundamentals Course (online)
- HL7 FHIR Foundational Implementer Exam Prep Course (online)
- HL7 FHIR Certification Bundle (on-demand recordings)

Training helps, but HL7 notes that nothing replaces knowing and applying the specification.
